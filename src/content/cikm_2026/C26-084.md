## Коротко

SEDRec делает семантику отдельной continuous denoising-целью: next-item embedding и semantic token восстанавливаются совместно из шума. Это diffusion в пространстве embeddings, а не генерация дискретных semantic IDs.

## Задача и мотивация

ID-based diffusion может хорошо моделировать переходы, но не сближать семантически похожие товары при малом feedback. Добавленный semantic loss иногда остаётся лишь вспомогательным training-сигналом и слабо влияет на генерацию из шума. Авторы предлагают включить semantic representation следующего товара непосредственно в target space диффузии.

## Как работает метод

1. Sentence-T5 офлайн кодирует метаданные каждого товара. Semantic table и проекция в hidden dimension по умолчанию заморожены, чтобы anchor не дрейфовал вместе с recommendation-моделью. В отличие от SID tokenizer здесь сохраняются непрерывные векторы.
2. Backbone на основе ADRec использует causal attention для истории и diffusion Transformer для next-item representation. Семантические embeddings исторических товаров агрегируются в дополнительное conditioning. История остаётся чистой; Gaussian noise добавляется только к target item token и отдельному semantic token.
3. В training semantic target берётся из ground-truth next item. Оба target-related tokens зашумляются на одном noise level и совместно восстанавливаются. Semantic-to-target mixing добавляет предсказанный semantic vector в next-item vector; промежуточный cosine alignment также направлен на фиксированную семантику target.
4. Loss сочетает next-item CE, ID reconstruction, semantic reconstruction и intermediate alignment. В inference правильный next item неизвестен: оба tokens стартуют с Gaussian noise, conditioning берётся только из истории. Восстановленный target сравнивается с item embedding table для ранжирования. Включение семантической цели в обучение само по себе не означает использования ответа в serving.

## Эксперименты и результаты

Amazon Sports, Beauty и Toys оцениваются с leave-one-out и full-item ranking без negative sampling. История ограничена 50 событиями, размерность равна 128; causal и diffusion modules имеют по два Transformer blocks. Default diffusion steps — 32. Hyperparameters semantic losses и training mixing подбираются по validation, inference mixing фиксирован на 0,1.

В таблице 2 Beauty HR@10 достигает 0,0831 против 0,0789 у ADRec, NDCG@10 — 0,0478 против 0,0461. На Sports сильнейший baseline CaDiRec даёт HR@10 0,0426, SEDRec — 0,0436; это небольшой прирост, а не универсально крупный эффект семантики. На Toys HR@10 0,0883 против 0,0856 у ADRec. Авторы отмечают significance p<0,05, но число повторов и полные доверительные интервалы не раскрывают в таблице.

Абляция в таблице 3 показывает особенно важную роль history semantic conditioning: на Beauty HR@5 падает с 0,0564 до 0,0395 без него. Удаление semantic reconstruction даёт 0,0554, mixing — 0,0540. Удаление intermediate alignment оставляет округлённые Beauty HR@5/NDCG@5 неизменными: 0,0564/0,0392. Поэтому нельзя описывать каждый компонент как одинаково существенный на каждом датасете.

Приложение A.2 проверяет более общий принцип на DiffuRec: Beauty NDCG@5 растёт с 0,0386 до 0,0397, Sports — с 0,0199 до 0,0212 (таблица 4). Это поддерживает перенос semantic targets, но не доказывает перенос всего token-wise pipeline без адаптации. Анализ числа шагов показывает компромисс: 64 шага дороже 32 и не улучшают accuracy. Training-time runtime и inference-time iterative cost рассматриваются отдельно.

## Ограничения и практический смысл

Метод интересен как способ сделать semantic representation частью generative objective, сохранив item-ID scoring. Офлайн семантический кэш убирает вызовы language encoder при каждом запросе, но не отменяет 32 последовательных denoising steps и final-catalog scoring.

Моя оценка: t-SNE визуализации geometry не являются количественным доказательством устранения embedding collapse. Требуются matched-compute baseline с такой же denoising schedule, сравнение с простым history-semantic fusion и исследование новых товаров. Группы пользователей с короткой историей — не полноценная оценка zero-history cold-start. Стоимость обновления metadata embeddings и ограничения fixed semantic anchor также существенны при дрейфе каталога.

## Вопросы авторам

1. Какой эффект semantic token остаётся поверх сильного history-semantic conditioning при одинаковом параметрическом и compute budget?
2. Как инициализируется замороженная проекция Sentence-T5 и насколько результат зависит от её seed и размерности?
3. Можно ли сохранить качество при distillation до нескольких denoising steps для строгого latency budget?
4. Как семантический anchor ведёт себя при изменении metadata и появлении новых item IDs без collaborative истории?
