## Коротко

SGLP использует LLM-семантику как structural prior для обучаемого гибридного графа в cross-domain sequential recommendation.

## Задача и мотивация

Разреженные interaction graph оставляют малоактивных пользователей и товары почти изолированными. Междоменные методы, требующие наблюдаемого перекрытия, не всегда создают для них пути передачи информации. Содержательные embeddings LLM предлагают альтернативный способ связать объекты, но эти связи нужно адаптировать к реальному поведению.

## Как работает метод

1. LLM формирует item semantic embeddings и global semantic profiles пользователей.
2. Semantic-Guided Graph Modeling дифференцируемо строит task-adaptive hybrid graph.
3. Семантическую близость преобразуют в обучаемые collaborative connections, дополняющие наблюдаемые рёбра.
4. Semantic-Behavioral contrastive alignment согласует виды представления; Bi-Level Sequence Prediction уменьшает отрицательный перенос между доменами.

## Эксперименты и результаты

По аннотации SGLP превосходит state-of-the-art baseline на трёх реальных Amazon-датасетах. Численные улучшения, плотность добавляемого графа, стоимость semantic priors и protocol temporal split не указаны. Поэтому отдельно проверить выигрыш именно у изолированных узлов по доступному тексту нельзя.

## Ограничения и практический смысл

Для собственного применения стоит проверить, не отражает ли новый граф преимущественно общие категории вместо индивидуального предпочтения. User profiles должны строиться из доступной на момент рекомендации истории. При больших каталогах также важен способ ограничить число потенциальных семантических рёбер.

Работу полезно рассматривать как перевод содержательных знаний в топологию, а не как замену GNN большим языковым ranker. В пилоте стоит визуализировать типы добавленных связей и измерить их точность на будущих взаимодействиях. Срезы по overlap пользователей и по степени исходных узлов помогут понять, восстанавливает ли новая структура перенос именно там, где наблюдаемый collaborative граф недостаточен.

## Вопросы авторам

1. Как ограничивается число кандидатных рёбер hybrid graph, чтобы differentiable structure learning масштабировался на миллионы товаров?
2. Какие признаки в user global profile вычисляются только по train-history и как исключается перенос будущего междоменного поведения?
3. Есть ли отдельный результат для полностью изолированных узлов, показывающий пользу semantic graph сверх увеличения общей плотности связей?
4. Какая абляция отделяет Semantic-Behavioral Alignment и Bi-Level Prediction от эффекта фиксированного графа семантических соседей?
